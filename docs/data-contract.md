# 工作簿资料

支持无宏OOXML工作簿，包成员路径按关系URI相对所在成员解析，TargetMode=External只保留外部关系，不连接。共享公式的si仅在单个工作表中有效，基公式f带ref区域，其他从属f只带si，乱序XML不改变对应关系。

公式不求值。支持词法范围为A1单格/矩形范围、可带单引号转义表名、绝对/相对混合坐标、数字、双引号字符串、算术比较运算、括号、逗号和普通函数名；拒绝展开结构化表引用、外部工作簿引用和动态数组专用语法但保留原式。相对引用超出Excel行列边界记录展开失败，不截断。公式缓存与公式类型独立保留。

日期只按date_style_ids显式选择，风格表仍保存numFmtId等原始样式引用；1900序号60含小数部分也标虚构日期。其他数值不因看似日期擅自转换。百分比保留原始底层Decimal及样式，不乘100。正文不将合并表头填充规则当数据值规则。

当前domain只列ZIP包成员，不读取工作表单元格。

共享公式基格位于ref区域左上角，合成源包含XML物理行节点乱序的变体，坐标身份不随节点顺序改变。缓存值只按来源保存，不因公式未执行而声称缓存正确或最新。
